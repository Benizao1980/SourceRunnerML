# Salmonella pilot data

Do not commit restricted, identifiable, or large raw genomic datasets here.

This directory should eventually contain either:

- a small redistributable example subset; or
- a script/instructions for recreating the pilot dataset from a public source such as EnteroBase.

Document the exact source, access date, inclusion/exclusion criteria, source-label harmonisation rules, and any subsampling used for the worked example.

Planned pilot fields include isolate ID, raw source, harmonised source, geography, year, serotype, genomic cluster identifiers where available, and cgMLST allele calls.
